## 证据基线与限制

- 仅读取源码、内容定义及素材文件名；未执行旧 PHP，未读取玩家存档、留言、拍卖、排行或战报文件内容，未发布凭据。
- 基线包含 60 个 PHP 和 2 个 CSS 文件。按相对路径排序，将每个文件的 SHA-256 与路径合成的调查指纹为 `c9d69bb568797056abf0ae8f7afb4d8c350a802bc1476e090ff4b08067289a8f`。行号对应当前工作区，旧源码尚无 Git 提交基线。
- 静态调查能证明分支、入口和写入顺序存在，不能证明旧站实际发生过某次故障，也不构成负载或运行正确性验证。
- 内容清单从去除注释、保留字符串与行号的源码中抽取已知定义和字面量。交叉引用核验限于报告明确列出的关系；不是完整 PHP 解析器，也尚未覆盖所有怪物战术、掉落、技能效果和附加效果的动态引用。
- 逐技能效果、公式、舍入、随机抽样顺序及边界场景，分别由内容模型、战斗契约和内容提取议题继续定稿。没有把试算脚本或手册直接当作生产规则。
