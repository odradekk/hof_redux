## 需运行期或进一步语义验证的疑点

- `data.land_appear.php` 的 `horh` 仅在服务器时间 02:50–02:59 加入；静态清单不证明入口实际可达。
- `data.enchant.php` 包含未加引号的 H00/HM0 等 case 标签；在旧 PHP 版本中可能依赖未定义常量退化为字符串，现代 PHP 行为不同，必须迁移为显式稳定 ID。
- 定义文件含可执行逻辑；例如 `data.monster.php:343,3930,3935` 调用随机函数，另有小时条件。必须将内容定义、遭遇生成和随机输入分开建模，不能把 case 体直接当 JSON。
- `data.gd_*`、manual、tutorial 是展示/说明内容，未将其 HTML 文本中的数字当成正式定义。
- “孤立”只能证明未被本次所列静态关系引用；管理入口、战斗代码或动态拼接可能引用，因此不把未引用集合直接判为废弃。
