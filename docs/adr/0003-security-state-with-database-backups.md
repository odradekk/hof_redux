# 首期凭据与账号状态随数据库备份恢复

首期将玩家凭据与账号生命周期和游戏状态一同保存在 SQLite，一同备份恢复，不另建异机安全变更日志。用户在[运行方案](../design/runtime.md) Q7 明确接受备份窗口内改密、恢复码轮换/消费、停用和删号可能回退，以降低无邮件、单机运营的恢复复杂度。

恢复新代次会撤销旧会话和旧页面请求，但不会让备份中的旧密码或恢复码自动失效；恢复时必须公布恢复点并提示玩家核对、改密。管理员身份另由服务器管理者重新授权，内部账号身份不复用，不能用登录名合并新旧身份。

若以后要求安全变更不可随备份回退，必须重新设计异机持久记录及其失败处理、业务确认和恢复顺序；不能只改提示文字，或声称会话撤销已消除旧凭据重新有效的可能。
